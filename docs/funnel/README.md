# Лендинг-воронка yool.live — точка старта

Новая итерация лендинга: вместо 3D-сцены «Один рейс» — продающая страница по образцу vibeyard.app. Первый экран сразу говорит, что это и кому, дальше только настоящий продукт. Начато 1 ноября 2026.

Каждая новая сессия читает этот файл первым и дописывает строку в «Журнал» внизу.

## Порядок работы

1. **Идея** — готово.
2. **Дизайн** — макет страницы готов; записи роликов (ru) сняты — `recordings.md`, файлы в `recordings/media/`.
3. **Шаги** — готово: план по сессиям `plan.md`, тексты `copy/ru.json` (uz/en — позже).
4. **Код** — пишет модель Fable по `plan.md`: сессии 1–4 сделаны (01.11: каркас, первый экран, «Как это работает», карусель, три функции, «Водителям», старт с формой заявки, вопросы, финал), сессии 4а «Полировка медиа» и 4б «Как это работает v2» (шаги + одна большая сцена, три новых ролика) и 5 «SEO, аналитика, UTM» и 6 «Проверка» тоже сделаны — **код готов, ветка `landing/funnel` ждёт PR** (описание — `pr.md`).
5. **Выкладка** — владелец: GitHub Variables со счётчиками, PR в `main`, после выкладки — Вебмастер/Search Console, sitemap, проверка превью ссылки (`pr.md`, раздел «После выкладки»).

## Решения владельца

- Платят грузовладельцы, диспетчеры, транспортные компании — страница говорит с ними. Водитель — вторая кнопка «Я водитель» и один блок.
- Главная кнопка — «Попробовать бесплатно». Цену не называем.
- 3D убираем полностью вместе с three.js (`components/world3d`, `components/topdown`, `public/3d`).
- Страница светлая. Ориентир — СНГ, не только Узбекистан. Языки ru (основной), uz, en.
- Главная картинка — записи настоящего кабинета и приложения, снимаем вместе с владельцем.
- Шрифты: заголовки Wix Madefor Display 800, одно акцентное слово — курсив Cormorant Garamond 600 цветом `accent`; текст Golos Text; подписи JetBrains Mono.
- Тексты: **заголовок цепляет, подзаголовок раскрывает** («Отслеживаем даже без интернета» + как это работает). Не писать того, чего продукт не делает вовсе.
- Блока «боль» нет: боль уже в заголовке «Хватит звонить водителю».
- Аналитика: Яндекс Метрика + GA4, Вебмастер + Search Console, потом реклама. Цель «регистрация» требует счётчика и UTM и в app.yool.live.

## Страница сверху вниз (макет)

1. Шапка (тёмная): логотип, меню, RU, «Войти», «Попробовать бесплатно».
2. Первый экран: «Хватит звонить *водителю.*», подзаголовок, две кнопки, окно кабинета + телефон водителя.
3. «Подключение за три минуты» — три шага с крупными цифрами; на телефоне лента.
4. «Звонить больше *незачем*» — карусель из 12 преимуществ.
5. Три функции с записями, без заголовка, запись чередуется слева/справа: без интернета · клиент по ссылке · простой.
6. «Водителям: одна кнопка на каждый шаг» + значки магазинов.
7. Тёмный блок «Первый груз за три минуты. *Бесплатно.*» + форма «Большой автопарк?».
8. Вопросы (5).
9. Финал «Хватит звонить *водителю.*» и подвал.

## Открытые вопросы (не блокируют дизайн)

- Маршрут и время в пути считаются только по графу Узбекистана (Valhalla). Шаг «маршрут посчитается сам» вне UZ пока неправда — до рекламы на СНГ расширить граф.
- В каких странах доступны приложения в Google Play и App Store — проверить.
- До рекламы закрыть OTP `567657` и сброс пароля.
- Значки магазинов: русские поставлены (сессия 3); узбекские — вместе с переводами.
