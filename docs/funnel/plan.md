# Вёрстка лендинга-воронки — план по сессиям

Для сессии, которая пишет код (модель Fable). Читать первым этот файл, потом `README.md` рядом (решения владельца и журнал). Каждая сессия делает свой этап целиком, проверяет по «Приёмке», коммитит в ветку `landing/funnel` и дописывает строку в «Журнал» внизу этого файла. Не пушить и не мержить — это делает владелец.

Сейчас на проде (`main`) 3D-лендинг «Один рейс». Новая страница его полностью заменяет. Узбекский и английский — позже, отдельной сессией; сейчас только русский (см. «Языки»).

## Стек и что сносим

Next.js 15.1 (App Router, `output: "standalone"`), React 19, Tailwind v4 (`@tailwindcss/postcss`, без конфиг-файла, токены в `app/globals.css` через `@theme`), next-intl 3 (`app/[locale]/`, `messages/*.json`, `middleware.ts`, `i18n/request.ts`), lucide-react. Пакетный менеджер — pnpm. Деплой: push в `main` → Docker (`Dockerfile`) → прод, workflow `.github/workflows/ci-cd.yml`.

Удалить полностью (сессия 1):
- `components/world3d/`, `components/topdown/`, `public/3d/`, `public/hero-wide.webp`, `public/hero-narrow.webp`;
- зависимости `three`, `@types/three`, `gsap` (их используют только эти папки — проверить `grep` после удаления);
- неймспейсы `trip` и `td` в `messages/*.json`, флаги `?map=`, `?look=`, `?v=` если где-то остались;
- `components/sections/Start.tsx`, `Faq.tsx`, `FinalCta.tsx`, `components/ui/Accordion.tsx` — переписываются под новый макет (логику отправки формы из `FinalCta.tsx` перенести, см. сессию 4).

Не трогать: `app/api/leads/route.ts` (прокси заявок в api-server, работает), `docs/3d/` (история), `lib/site.ts` — только поправить ссылки (см. ниже).

## Архитектура

- Блоки страницы — `components/funnel/<Block>.tsx`, страница `app/[locale]/page.tsx` собирает их по порядку макета: `Nav` → `Hero` → `HowItWorks` → `Benefits` → `Features` → `Drivers` → `StartBlock` (+ `LeadForm`) → `Faq` → `FinalCta` → `Footer`. Серверные компоненты по умолчанию; `"use client"` только где нужен браузер (видео, карусель, форма, меню на телефоне).
- Общие кусочки — `components/funnel/ui/`: `Button` (главная `accent-deep` + `shadow-glow`, вторая `card` + `line-soft`), `AccentWord` (курсив Cormorant, `accent`, 1.12em), `Eyebrow` (mono label), `BrowserFrame` (рамка окна с адресом `app.yool.live`, рисует страница — в роликах рамок нет), `PhoneFrame`, `LoopVideo`, `StoreBadges`.
- Якоря: `#how`, `#drivers`, `#faq`; «Я водитель» ведёт на `#drivers`.
- Ссылки — только из `lib/site.ts`. Исправить там: `privacy` → `https://app.yool.live/privacy-policy`, `terms` → `https://app.yool.live/terms-of-service` (сейчас ведут на несуществующие `/privacy`, `/terms`). «Попробовать бесплатно» → `SITE.register` с UTM (сессия 5), «Войти» и «У меня уже есть аккаунт» → `https://app.yool.live/login`.
- Шрифты через `next/font/google`, подмножества `latin` + `cyrillic`: Wix Madefor Display 800, Cormorant Garamond italic 600, Golos Text 400/500/600, JetBrains Mono 500. Onest больше не нужен. Предзагружать только Wix Madefor Display и Golos 400 (`preload: false` у остальных).

В роликах уже есть наезды камеры на место действия и кружки касаний — поверх ничего не рисовать.

**`LoopVideo`** (клиентский компонент):
- `<video muted playsInline preload="none" poster=…>`, `aria-label` из `copy/ru.json` (`…video`). Без звука, без контролов.
- Играет только когда виден (IntersectionObserver, порог ~0.25), на выходе из вида — пауза. `preload="none"` у всех, кроме пары первого экрана (`preload="metadata"`).
- `prefers-reduced-motion: reduce` → только постер (`<img>`), видео не грузится.
- Размеры заданы заранее (`aspect-ratio` у рамки) — никакого сдвига вёрстки при загрузке.
- Постер первого экрана — кандидат LCP: `<img src="/media/01-hero-cabinet.ru.webp" fetchpriority="high" width height>` под видео (или `poster` + `<link rel="preload" as="image">`); остальные постеры `loading="lazy"`.
- Пара первого экрана: без атрибута `loop`. Когда кончается окно (#1, оно длиннее), оба ставятся на `currentTime = 0` и запускаются вместе; телефон, кончившийся раньше на 0,07 с, ждёт. Обе на паузе, если первый экран не виден.

### 2. «Как это работает» и карусель преимуществ
- `HowItWorks` (`#how`): eyebrow, заголовок без курсива, lead; три шага — огромные серые цифры 1-2-3 над чертой, под ними заголовок и текст, кадры 16:10 выровнены по низу. На телефоне шаги — горизонтальная лента со snap.
- `Benefits`: eyebrow, заголовок с курсивом «незачем», подсказка «листайте»; 12 карточек в горизонтальной ленте (CSS scroll-snap), лента выходит за правый край контейнера; на компьютере кнопки «Назад/Дальше» (прокрутка на ширину карточки), клавиатура и тач работают. Иконки — lucide, 20 px в плитке (подобрать по смыслу: WifiOff, Link, Timer, FileText, Clock, Bell, BatteryLow, MapPin, Smartphone, Battery, Users, History).
- Без библиотек каруселей.
- **Приёмка:** скриншоты 390/1440 против макета; карусель листается мышью, кнопками, тачем (эмуляция `hasTouch`); на 360 нет горизонтальной прокрутки страницы (`document.documentElement.scrollWidth === innerWidth`).

## Бюджеты и проверка

- LCP < 2,5 с, JS первой загрузки ≤ 100 КБ gzip, CLS < 0,05 — на профиле `tools/vitals.mjs` (360×640, CPU ×4, ~1,6 Мбит/с). Нынешний прод для сравнения (01.11): LCP 3,7 с, JS 199 КБ, шрифты 147 КБ, высота страницы на 360 px — 9985 px.
- На 360×640 без прокрутки: заголовок, подзаголовок, главная кнопка.
- Нет горизонтальной прокрутки страницы ни на одной ширине.
- Анимация появления блоков — один раз, сдвиг не больше 16 px, выключается при reduced motion; никаких параллаксов и привязки к прокрутке.
- Скрипты проверки ставить так: `mkdir -p <scratchpad>/pw && cd <scratchpad>/pw && npm i playwright-core@1.48.2`, браузер — `/usr/bin/google-chrome`. Если сеть медленная (бывает), искать готовый `node_modules` в старых scratchpad: `ls /tmp/claude-1000/*/*/scratchpad/pw/node_modules`.

## Грабли

- **Не делать копию репо со ссылкой `node_modules` на настоящую папку** — `pnpm build` в копии вычистил настоящий `node_modules` (11.10). Копию для прод-сборки ставить отдельно: `pnpm install --frozen-lockfile --offline`.
- Dev-сервер на `:3123` часто уже запущен прошлой сессией из этого репо — проверить (`ss -ltnp | grep 3123`) и не стартовать второй. `pnpm --dir <путь к репо> dev -p 3123`.
- `npx prettier` в репо нет — не запускать, переформатирует файлы целиком.
- Сеть до Google медленная: шрифты `next/font/google` при сборке качаются долго, повторить при таймауте.
- Скриншоты/видео в headless Chrome: ждать `waitUntil: 'load'`; MapLibre тут нет, но у видео первого кадра может не быть до прокрутки — для скриншотов ждать постеры.
- `pkill -f <шаблон>` убивает и свою же оболочку, если шаблон есть в тексте команды — убивать по PID.
- Next 15.1.12 + React 19.0.9 — версии с фиксом React2Shell (CVE-2025-66478); при обновлении зависимостей не откатиться ниже.
